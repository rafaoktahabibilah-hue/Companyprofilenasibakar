# Genre Filter Demo

Branch `fitur-genre` — Fitur filtering/klasifikasi genre komik.

**File:** `genre-demo.html` — standalone, tinggal buka di browser.

## Fitur
- Chip genre yang bisa diklik
- Filter manga berdasarkan genre
- Badge genre aktif + tombol hapus filter
- Grid responsive
- 15 sample manga dengan berbagai genre

## Genre yang tersedia
Action, Adventure, Comedy, Drama, Fantasy, Isekai, Military, Music, Psychological, Romance, School, Slice of Life
